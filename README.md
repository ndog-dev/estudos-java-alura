# Estudos Java — Alura

Repositório de estudos e exercícios práticos do curso de Java da Alura, com foco em backend e Spring Boot.

## Sobre

Este repositório documenta minha jornada de aprendizado em Java. Cada módulo do curso é implementado como um pacote dentro de um projeto Maven único, seguindo a convenção `br.com.estudosjava.<modulo>`.

> Nota: os exercícios dos módulos iniciais (Fundamentos de POO, Condicionais, Loops e Switch/Menu) foram feitos antes da criação deste repositório e não foram preservados.
